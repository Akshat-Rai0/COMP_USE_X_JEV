    Design rules for the real screen

    • Length means time. The timeline is drawn to scale, so a slow step looks slow. Expect the Driver and the LLM, not Jev, to dominate it.
    • Confidence always sits next to the gate it was compared with.
    • Jev gives no reasons, so the screen shows probabilities and never invents an explanation.
    • A run shows as confirmed only when the code check on the real end state passes.
    • A voice correction gets its own marker in the step list, placed exactly where it landed in the loop, never merged into the step before or after it.
    • Every number opens its StepRecord.
    • Colour always comes with a word or a symbol, and every control works from the keyboard.
