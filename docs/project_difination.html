Project definition

Reflex Arc is a macOS agent that operates real apps by splitting its thinking in two. A fast decision model handles each small step. A slower language model steps in only when the fast one is unsure.

The analogy. Touch a hot pan and your hand pulls back before you have consciously decided anything. That is a spinal reflex: fast, narrow, and good at one job. Deliberate thinking happens in the cortex, and it only gets involved when the reflex has no good answer.

Here Jev is the spine, the planner LLM is the cortex, and Cua Driver is the eyes and hands. Noul questions confirm that each move worked.

The question this project answers

How much of a desktop agent's inner loop can a System One model handle alone, how fast and cheap is that in practice, and how often is it confidently wrong?

TypeSafe publishes speed, cost, and calibration claims for Jev. This project tests them on one real desktop task and reports what it measures, not what the vendor reports.

The hero task

The hero task is chosen at the end of week 2, after the perception spike shows which apps expose a usable UI tree. Until then every example in these docs uses a sample task, create a reminder from a sentence, only to make things concrete.

A task qualifies when all of these hold:

  • The app exposes a usable UI element tree (checked in the spike)
  • It takes at least 8 steps and needs at least one typed-in text value
  • The end state can be checked by code, not only by Jev
  • It is reversible inside the sandbox and touches no real account, money, or message

Deliverables

  • A public repo with a README that states measured numbers and a failure analysis
  • A demo video of about 90 seconds: screen recording beside the live trace
  • The run console (see UI)
  • These five docs, kept current, under /docs
  • One resume bullet that uses only numbers from your own runs

Constraints and assumptions

  • Solo, about 12 weeks from Sep 28 to Dec 20, with a reduced-hours window from Nov 9 to Nov 25 (see Roadmap).
  • Jev is in early access, so access on day one is not guaranteed.
  • Everything runs locally on an Apple Silicon Mac except the Jev and LLM API calls.
  • Jev's speed and cost figures are the vendor's own, measured from the US. This project measures them from India.
  • The agent never touches a real account, money, or message.
